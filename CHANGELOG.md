# 📦 Changelog — Laravel SeedBuilder

Все значимые изменения этого пакета документируются здесь.

---

## [1.0.0] — 2025-05-02

### 🎉 Первоначальный релиз

#### 🛠️ Основное

- [x] Создание таблицы по схеме или автоинференции из данных
- [x] Вставка сидов через JSON или массив
- [x] Поддержка `nullable`, `default`, `unique`, `primary`, `foreign`, `enum`
- [x] Работа без моделей и фабрик

## [1.0.2] — 2025-05-02

#### 🧪 CLI-команды

- `php artisan seedbuilder:export` — экспорт таблицы в JSON
- `php artisan seedbuilder:generate` — генерация шаблона сидера по структуре таблицы

## [1.0.3] — 2025-05-02

#### 🧩 Расширенные возможности

- [x] Поддержка шаблонов `faker:*` и `now()` в `defaults` и `rows`
- [x] Валидация значений:
    - соответствие схеме
    - проверка enum-значений
- [x] Поддержка вложенных таблиц (`foreign_key` → `insertGetId`)
- [x] Управление очисткой данных:
    - `truncate: true`
    - `delete_where: {...}`

#### 🌀 Расширяемость

- [x] Установка как Laravel-пакета
- [x] Публикация конфига `config/seedbuilder.php`
- [x] Использование фасада `SeedBuilder::insert(...)`

#### 🧾 Логгирование

- [x] Логи `info(...)` при:
    - создании таблицы
    - очистке или удалении
    - вставке / upsert
- [x] Управление логами через конфиг `log => true|false`
