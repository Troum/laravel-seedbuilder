# 📊 Laravel SeedBuilder vs Laravel Core Tools

Сравнение возможностей между **Laravel SeedBuilder** и стандартными инструментами Laravel (`Migrations + Seeders + Factories`).

---

## ✅ Таблица сравнения

| Возможность / Подход                               | Laravel Migrations + Seeders + Factories     | ✅ SeedBuilder                                 |
|----------------------------------------------------|----------------------------------------------|-----------------------------------------------|
| **Создание таблицы вручную**                        | ✅ Да — `Schema::create(...)`                | ✅ Автоматически по JSON или inferred          |
| **Сидирование без модели**                          | ❌ Нет — требуется модель или query builder   | ✅ Да — данные вставляются напрямую            |
| **Сидирование прямо в миграции (`up`)**             | ⚠️ Не рекомендуется / вручную                | ✅ Да — через `SeedBuilder::insert()`          |
| **Декларативный формат (JSON/array)**               | ❌ Нет — только PHP-код                       | ✅ Да                                          |
| **Инференция типов из данных**                      | ❌ Нет                                        | ✅ Да — `SchemaInferrer` анализирует `rows`    |
| **Поддержка `enum`, `foreign`, `default`, `nullable`** | ⚠️ Частично, вручную                        | ✅ Да, через `schema`                          |
| **Импорт данных без модели (напр. из API или CSV)** | ⚠️ Нужно писать вручную                      | ✅ Да — можно конвертировать в JSON            |
| **Экспорт таблицы в JSON для репликации**           | ❌ Нет                                        | ✅ Да — через `seedbuilder:export`             |
| **Генерация схемы сидера по таблице**               | ❌ Нет                                        | ✅ Да — через `seedbuilder:generate`           |
| **Поддержка `faker:`, `now()` в данных**            | ❌ Нет                                        | ✅ Да — автоматически                          |
| **Upsert/Replace режим вставки**                    | ⚠️ Только вручную через `updateOrCreate()`   | ✅ Да — `mode: upsert`, `unique: [...]`        |
| **Вложенные таблицы / foreign ключи**               | ❌ Нет                                        | ✅ Да — рекурсивная вставка с `foreign_key`    |
| **Удаление данных перед вставкой (`truncate`, `delete_where`)** | ❌ Нет                                 | ✅ Да                                          |
| **Валидация схемы перед вставкой**                 | ❌ Нет                                        | ✅ Да — `field exists`, `enum valid`           |
| **Удобен для больших проектов с фабриками**         | ✅ Да                                         | ❌ Нет — не заменяет фабрики/модели            |
| **Гибкость логики сидирования (условия, loops)**    | ✅ Да — полный PHP                            | ❌ Ограничено static config                    |
| **Применим на продакшене / CI/CD без `db:seed`**    | ⚠️ Только если явно вызван сидер             | ✅ Да                                          |

---

## 🟢 Что выбрать

| Сценарий                                 | Что выбрать                                 |
|------------------------------------------|---------------------------------------------|
| Быстрая вставка тестовых данных          | ✅ SeedBuilder                               |
| Сложная логика сидирования, loops        | ❌ Оставь Seeder + PHP                       |
| Импорт JSON / API-таблиц                 | ✅ SeedBuilder                               |
| Full-stack Eloquent + Factory            | ✅ Классика Laravel                          |
| CI/CD миграции с данными                 | ✅ SeedBuilder (или вручную в миграции)      |
| Прототипы, MVP, внутренние панели        | ✅ SeedBuilder                               |
| Продакшн-схема с кастомной бизнес-логикой| ✅ Laravel ORM и миграции                    |
